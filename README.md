# Верни рабочий стол

Личный лаунчер для Windows 10. Собери программы, папки, файлы и сайты для занятия и открой их одной кнопкой.

## Запуск

1. Установи [Python 3.10 или новее для Windows](https://www.python.org/downloads/windows/), если его ещё нет. В установщике оставь компонент Tcl/Tk и включи добавление Python в PATH, если этот параметр доступен.
2. Распакуй архив в обычную папку и дважды щёлкни по `start.cmd`.

Из терминала приложение также запускается командой `py -3 app.py`.

## Первый рабочий набор

1. Выбери **Учёба**. Нажми **+ Тема** и создай «Математика». Если нужна вложенная тема, выбери «Математика» и создай внутри неё «Производные».
2. Выбери «Производные» и нажми **+ Ресурс**. Добавь папку с задачами, файл конспекта или ссылку на занятие. Ты также можешь выбрать программу или ярлык. Если программе нужны аргументы, укажи их в карточке ресурса.
3. Нажми **Открыть всё**, чтобы запустить ресурсы выбранной темы. Двойной щелчок в списке открывает отдельный ресурс.

Рабочие наборы и последняя выбранная тема сохраняются в `%LOCALAPPDATA%\DesktopRestore\workspaces.json`. Удаление ресурса из приложения удаляет его запись из набора. Сами файлы хранятся на своих местах.

## Исходники

- `app.py` содержит интерфейс Tkinter.
- `workspaces.py` хранит настройки и открывает ресурсы.
- `start.cmd` запускает приложение на Windows.
