# Верни рабочий стол

Личный лаунчер для Windows 10. Собери программы, папки, файлы и сайты по темам и открой всё нужное одним нажатием.

## Установка

Скачай `DesktopRestore-Setup.exe` из [Releases](https://github.com/mihailmoskalenko08-eng/desktop-restore/releases), запусти установщик и открой **Верни рабочий стол** из меню «Пуск». Ярлык на рабочем столе можно добавить при установке. Сборка рассчитана на Windows 10 версии 1809 и новее, x64.

## Первый рабочий набор

1. Выбери **Учёба** и создай тему через **+ Тема**. Темы можно вкладывать друг в друга.
2. Нажми **Добавить**. Найди программы из меню «Пуск» и отметь нужные. Для сайта, пути к программе, файла или папки выбери **Добавить вручную**. Ярлык, файл или папку также можно перетащить в тему.
3. Нажми **Открыть всё** или открой один ресурс нажатием на карточку.

В **Настройках** можно выбрать светлое, тёмное или системное оформление, один из 12 акцентов или свой цвет по HEX-коду или на цветовой панели, а также отключить анимации. В разделе **О приложении** указаны версия, путь к данным и ссылка на релизы.

Рабочие наборы и последняя тема хранятся в `%LOCALAPPDATA%\DesktopRestore\workspaces.json`. Новый интерфейс читает этот же файл. Установщик кладёт программу в отдельную папку, а удаление приложения оставляет рабочие наборы.

## Разработка и сборка

Для запуска из исходников установи зависимости командой `py -3 -m pip install -r requirements.txt`, затем выполни `py -3 app.py`. Сборку установщика выполняет workflow **Windows installer**. Ручной запуск сохраняет установщик в артефактах. Опция `publish` или тег `v0.4.1` публикуют установщик в Releases после сборки и проверки запуска.
